# Hi, I'm Joaquim Almeida 👋

### 3D Environment Artist · Architectural Visualization & Level Designer

I build immersive 3D worlds where architectural precision meets real-time game art.

My background in architecture shapes how I approach every space: proportion, light, circulation, and how a player or viewer moves through an environment. I bring that thinking into game engines and visualization pipelines to create environments that are both believable and fun to explore.

- 🏛️ Turning architectural designs into interactive, real-time experiences
- 🎮 Designing level layouts with clear pacing, visual hierarchy, and smooth gameplay flow
- 💡 Lighting scenes for atmosphere while staying within performance budgets
- 🧱 Building modular, game-ready assets with clean topology and PBR materials
- 🗿 Sculpting organic and hard-surface characters and props
